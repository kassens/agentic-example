# agentic-example

Baseline repository for controlled, agent-assisted software development in a medical-technology environment.

The repository defines a phase-gated V-model/waterfall process for requirements, design, risk management, implementation, verification, release, and maintenance. It is a starting point to be tailored within the company's approved QMS; it does not by itself establish regulatory compliance.

Start with [AGENTS.md](AGENTS.md) and the [documentation index](docs/README.md).
