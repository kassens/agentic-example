# Project Flow (Waterfall)

This project uses a strict, standardized waterfall process appropriate for German medtech environments.

## 1. Requirements
- Capture complete, approved requirements before implementation starts.
- Maintain traceability from requirements to design, implementation, and verification artifacts.

## 2. Design
- Produce and review system and component design documents before coding.
- Record interfaces, assumptions, risks, and acceptance criteria.

## 3. Implementation
- Implement only approved and traceable scope.
- Keep changes small and reviewable.

## 4. Verification
- Validate implementation against approved requirements.
- Record objective evidence from reviews and testing.

## 5. Release and Maintenance
- Approve releases through documented sign-off.
- Handle post-release changes through controlled change requests and re-verification as needed.
