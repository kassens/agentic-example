# Product-Specific Controlled Records

This directory is the repository entry point for approved product/project records. Create the applicable subdirectories described in `../repository-layout.md` when instantiating this template.

If an approved QMS, requirements, risk, test, or document-management system is the system of record, do not duplicate uncontrolled copies here. Instead maintain a controlled index containing:

- External record ID and title.
- Revision/baseline and approval state.
- Stable link or retrieval instructions.
- Owner and applicable product/release.
- Integrity identifier or checksum where required.

Agents may draft records but may not mark them approved or replace controlled external records with repository copies.
